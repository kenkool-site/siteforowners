# Default service-card images

These are the fallback photos shown on a tenant's **service cards** when the
business has no real images (no Google Maps photos, no booking-app images, no
uploads). One file per default service.

> **After adding, replacing, or removing any file here, run
> `npm run gen:service-images`** to refresh the manifest the code reads
> (`src/lib/templates/service-image-manifest.ts`). The build does not scan this
> folder at runtime.

## Naming convention

```
public/defaults/services/<business-type>/<service-slug>.<ext>
```

`<ext>` can be `jpg`, `jpeg`, `png`, or `webp`. If a slug has more than one file
(e.g. both `.jpg` and `.png`), `.png` wins and the generator warns you to delete
the stale one.

- `<business-type>` is one of: `salon`, `barbershop`, `restaurant`, `nails`,
  `braids`, `locs`. (The combined "Locs & Braids" type reuses the `braids/` and
  `locs/` files — it has no folder of its own.)
- `<service-slug>` is the service name, lowercased, with `&` → `and`,
  apostrophes removed, and every other run of non-alphanumerics → `-`.
  Examples: `Wash & Blowout` → `wash-and-blowout.jpg`,
  `Nail Art (per nail)` → `nail-art-per-nail.jpg`,
  `Men's Braids / Cornrows` → `mens-braids-cornrows.jpg`.

The slug is generated by `slugifyServiceName()` in
`src/lib/templates/service-images.ts`. The list of services lives in
`src/lib/templates/default-services.ts`.

## To swap a photo

Drop in a file with the same slug (any supported extension), then run
`npm run gen:service-images`. Use a landscape-ish image ~1600px wide; it renders
cropped to the card aspect ratio. If you change the extension (e.g. jpg → png),
delete the old file so the slug has exactly one.

## To add a service

Add `{ name, price }` to the right vertical in `default-services.ts`, drop a
matching `<service-slug>.<ext>` here, then run `npm run gen:service-images`.
`default-services.test.ts` fails if a service has no matching file, so a typo is
caught before it ships.
